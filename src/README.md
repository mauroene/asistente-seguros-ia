# Código fuente

El código de implementación y evaluación del proyecto se encuentra
integrado en los notebooks de Google Colab disponibles en la carpeta
`notebooks/` del repositorio.

Estos notebooks incluyen la preparación de datos, carga de modelos
preentrenados de Hugging Face, clasificación de consultas sobre seguros
de vida, cálculo de métricas y comparación de resultados.

La carpeta `src/` se conserva como parte de la estructura del proyecto
para una posible modularización futura del código.

En esta versión del prototipo no se desarrollaron scripts independientes,
ya que la implementación se realizó directamente en los notebooks.
